Schedule your next D&D session with one link

The hard part of a campaign is rarely the rules. It is getting a DM and three to six players, with jobs, kids and sometimes other campaigns, around the same table on the same evening, and then doing it again a few weeks later. A date poll turns the "which night works?" thread into one link everyone answers once.

Set up a poll for the next session

  1. Name it after the session. "Curse of Strahd, session 14" tells everyone which poll this is when the last one is still in the chat. Use the details box for how long you plan to play and whose place it is at.
  2. Add the nights your table can usually do. Under "Or repeat certain weekdays across a date range", pick Friday and Saturday, say, set the range to the next three or four weeks, and choose Add those days.
  3. Make each evening one start time. Under "What times?", offer time slots, set the window to 6:00 PM to 10:00 PM and set each slot to 4 hours. Every chosen evening becomes a single 6 PM start. If Saturday games start earlier, add a different window for Saturday only, such as 2:00 PM to 6:00 PM.
  4. Switch on maybe. The player who might be on call that weekend can say so instead of answering no.
  5. Set a voting deadline a day or two before the earliest date, so the poll closes itself and nobody adds a no after you have announced the session.

Reading the results for a quorum

Scheduler does not know who the DM is or how many players you need to run the game. The tally under each column covers it: find the evenings where the DM's row says yes, then take the one with the most yes answers among the players. The highlighted best date counts every row the same, a yes as two points and a maybe as one, so on a table where one person is essential, check that row before you announce.

Once you have picked, "Add to calendar" downloads a calendar file you can drop in the group chat so everyone has the session in their own calendar.

Recurring campaigns

A poll picks dates, not a repeating slot. Two ways to use it for a long campaign: poll the next month of candidate evenings in one go and see whether the same weekday keeps winning, which gives you a regular night; or make a short fresh poll whenever the next session is up in the air. If what you really want is a standing weekly time with no dates attached, a days of the week tool fits that better. The Crab Fit comparison covers one.

Questions

Do my players need an account?

No. They open the link, type a name, and tap yes or no on each evening. Their browser remembers their row, so they can change an answer later from the same device.

One of our players is in another time zone. Will the times confuse them?

Timed options show on each voter's own clock by default, with a switch to see them as you entered them. The page always says which time zone it is showing.

Someone dropped out after we picked a night. Can we pick again?

Yes. With the organizer link you can reopen voting, add another evening to the same poll, or remove one. Answers already given on the other evenings stay where they are.
